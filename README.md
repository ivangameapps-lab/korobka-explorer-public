# Korobka Explorer 0.5

Файловый менеджер на Rust/egui. Не использует окно Проводника Windows.

## Запуск

```powershell
cargo run --release
```

## Интерфейс

- Два оформления: «Матовый» — плотный синий градиент, и «Стекло» — реально прозрачные панели поверх акрила Windows. Настраиваемый акцентный цвет, мягкие световые пятна, шрифт Segoe UI.
- Собственная стеклянная шапка с перетаскиванием, сворачиванием, разворачиванием и закрытием окна.\n- Вкладки: `Ctrl+T`, `Ctrl+W`, `Ctrl+Tab` / `Ctrl+Shift+Tab`, средняя кнопка мыши закрывает вкладку.
- Адресная строка с кликабельными хлебными крошками; `Ctrl+L` или карандаш переключают ручной ввод пути.
- Слева — быстрый доступ (профиль, рабочий стол, документы, загрузки, изображения, видео) и диски; панель сворачивается до иконок и меняет ширину.
- Список — виртуализированная таблица (`egui_extras`) с колонками «Имя», «Размер», «Тип», «Изменён» и сортировкой.
- Плитка — адаптивная виртуализированная сетка с прокруткой только видимых строк.
- Ввод в поле поиска мгновенно фильтрует текущую папку — без обхода диска и фоновых потоков. Enter — поиск по текущей папке и подпапкам, кнопка с лупой — по всему диску.
- Панель «Свойства» показывает тип, размер, дату изменения и путь; открывается из шапки или контекстного меню.
- Контекстное меню: открыть, открыть папку в новой вкладке, копировать/вырезать, копировать путь, переименовать, свойства, удалить в корзину или безвозвратно.
- Правый клик по пустому месту открывает меню как в Проводнике: «Создать» (папка, текстовый документ, документ Word, таблица Excel, ZIP-архив, пустой файл), вставить, обновить, сортировка. Правый клик по папке — «Создать» внутри неё, правый клик по файлу или папке — «Создать ярлык» (`.lnk`).
- Кнопка с корзиной в шапке удаляет выделенное в корзину (`Del`), `Shift+Del` — безвозвратно (с подтверждением, отключается в настройках). После удаления строки сразу исчезают и из результатов поиска.
- «Действия» и «Настройки» (`Ctrl+,`) объединяют операции, вид, интерфейс и сброс индекса.
- В статусной строке — состояние, объекты, выбранное и его размер, режим вида, прогресс операции с отменой.

## Настройки

- Вид: список/плитка, компактные и полосатые строки, «папки сверху», показ скрытых и системных объектов.
- Оформление: «Матовый» / «Стекло» (прозрачные панели, акрил Windows), ползунок прозрачности, отключаемое размытие фона, акцентный цвет, анимации, панель свойств, боковая панель, плавный масштаб 80–135%.
- Язык: «Системный» (определяется по языку Windows), «Русский», «English». По умолчанию — системный; выбор сохраняется в сессии. При первом запуске на русской Windows интерфейс русский, на остальных — английский.
- Безопасность: подтверждение безвозвратного удаления.
- Поиск: сброс индекса и число потоков индексации (2–16). После файловых операций индекс помечается устаревшим и первый следующий поиск перестраивает его — это одноразовая нагрузка на CPU.
- «Сбросить настройки» возвращает значения по умолчанию, не закрывая вкладки и открытые папки.
- Настройки сохраняются автоматически через 0,4 с после изменения, при закрытии окна и по кнопке «Сохранить настройки» — в `%LOCALAPPDATA%\Korobka\session.json` (атомарная запись через временный файл).

## Файловые операции

- Мультивыбор: клик, Ctrl+клик, Shift+клик.
- `Ctrl+C` / `Ctrl+X` / `Ctrl+V` — копирование, вырезание, вставка в текущую папку.
- `Del` — в свою корзину (`%LOCALAPPDATA%\Korobka\trash`), `Shift+Del` — безвозвратно (по умолчанию с подтверждением). Клик по строке снимает фокус с поля поиска, поэтому `Del` сразу работает по файлам.
- `↑`/`↓` — переход по строкам, `Shift+↑`/`Shift+↓` — выделение диапазона.
- `F2` — переименование, `Enter` — открыть, `Backspace` — вверх, `F5` — обновить.
- `Ctrl+Shift+N` — новая папка, `Ctrl+A` — выбрать всё видимое, `Ctrl+,` — настройки.
- `Ctrl+Z` — отмена последней операции (копирование, перемещение, корзина, переименование).
- Корзина: **боковая панель → «Корзина»**. Показывает удалённые объекты и исходный путь из манифеста, позволяет восстановить в исходную папку (при занятом имени — с суффиксом), удалить выборочно или очистить всю корзину. Отдельного окна Проводника для неё нет.
- Длинные пути: абсолютные пути автоматически получают префикс `\\?\` (для UNC — `\\?\UNC\`) при обходе, копировании, перемещении, удалении, работе с корзиной и распаковке. В интерфейсе путь показывается без префикса. Открытие конкретного файла сторонним приложением может по-прежнему зависеть от этого приложения.
- Операции идут в фоновом потоке с прогрессом и кнопкой отмены.
- Если файл не удаляется, потому что его удерживает программа, приложение находит конкретный заблокированный файл (проверка `CreateFileW` с правом `DELETE`) и показывает список процессов через Restart Manager.
- Процессы можно закрывать выборочно. Сначала отправляется мягкое закрытие окна, затем при необходимости — принудительное; после закрытия удаление повторяется автоматически. `Enter` подтверждает, `Esc` отменяет.
- `explorer.exe` защищён от обычного закрытия: для него выполняется перезапуск Проводника. Системные процессы и службы не закрываются автоматически; для процессов с повышенными правами может потребоваться запуск от администратора. Несохранённые данные закрываемых программ могут быть потеряны.
- Копирование папки внутрь самой себя блокируется; junction/symlink не разворачиваются при удалении и копировании.

## Диски и типы файлов

- Список дисков через Win32: `GetLogicalDrives`, `GetDriveTypeW`, `GetVolumeInformationW`, `GetDiskFreeSpaceExW`.
- Показываются метка тома, тип и свободное место.
- Контурные иконки папок и файлов; тип и оттенок по расширению (изображения, видео, аудио, архивы, код, PDF, программы, документы).

## Поиск

- Живой поиск по папке не запускается: ввод только фильтрует уже загруженный список, поэтому не тормозит даже на огромных папках.
- `Enter` — поиск по текущей папке и подпапкам (первый раз строит кэш папки), лупа — по всему тому. Повторный поиск читает готовый индекс.
- Запрос разбивается на слова, все слова обязаны совпасть: `отчёт 2026`. Фразу с пробелами можно взять в кавычки: `"отчёт 2026"`.
- Маски `*` и `?`: `*.txt`, `отч?т`. Маска с `*` в начале или конце (`*.txt`, `report*`) сверяется с именем целиком, маска без крайних звёздочек (`отч?т`) — с любой частью имени.
- Слово с `\` или `/` ищется по полному пути: `users\ivan\doc`.
- Кнопка режима в поле поиска: «Точное имя» — имя файла должно совпасть целиком, «По части имени» — достаточно вхождения. Режим действует и на фильтр, и на поиск; переключение перезапускает активный поиск.
- Результаты ранжируются: точное имя, затем совпадение с начала имени или слова, затем вхождение; внутри группы сначала короткие имена.
- `Ctrl+F` — фокус в поле поиска, `Esc` — очистить поиск и фильтр.
- Индекс кэшируется в `%LOCALAPPDATA%\Korobka\index`: отдельно для тома и для папок, которые искали через «Действия».
- Первый поиск обходит диск и сразу фильтрует найденное, не собирая весь индекс в памяти; повторный читает кэш.
- Кэш читается потоково; полный путь папки хранится один раз на блок, а элементы — только именами и типом, поэтому индекс в 3 раза компактнее и читается быстрее.
- «Сбросить индекс» и файловые операции помечают кэш устаревшим; следующий поиск сам перестроит индекс.
- Кэш считается устаревшим через 7 дней; старый формат индекса (полный путь в каждой строке) читается без переобхода, новые индексы пишутся компактно.
## Производительность

- Списки, плитка и результаты поиска виртуализированы: рисуются только видимые строки.
- Папки читаются через Win32 `FindFirstFileW`/`FindNextFileW` в фоновом потоке; UI сразу показывает окно, а не ждёт диск.
- Последние 10 папок кешируются на 30 секунд — «Назад»/«Вперёд» срабатывают мгновенно.
- Сортировка больших папок параллельная (rayon), без аллокаций на каждое сравнение; размер, тип и цвет считаются при загрузке.
- Фильтр использует заранее рассчитанные имена в нижнем регистре и тот же движок, что и поиск; для папок от 20 000 объектов индексы пересчитываются параллельно (rayon).
- Ввод в поиск не обходит диск: показывается только отфильтрованный список, поэтому задержка не зависит от размера папки.
- Сопоставление не аллоцирует память на каждое имя: ASCII-поиск идёт через `memchr2` по первому байту, Unicode приводится к нижнему регистру в переиспользуемом буфере потока.
- Ранг совпадения считается за один проход по имени (раньше было до трёх проходов на слово).
- Индекс строится параллельно: обход дерева идёт в несколько потоков rayon, запись кэша — отдельным потоком. Профиль пользователя на ~860 000 объектов индексируется за ~1,0–1,4 с в зависимости от числа потоков.
- Поиск использует отдельный пул потоков: по умолчанию **8**, настраивается в «Настройки → Поиск → Потоки поиска» (2–16). Меньше потоков — ниже загрузка CPU, но индекс строится дольше. Общий пул rayon (12 потоков) остаётся для сортировки и интерфейса.
- Кэш читается блоками по 4 МБ; строки индекса разбираются один раз. 860 тыс. объектов — ~53 мс, 2,1 млн — ~0,13 с.
- Компактный индекс: ~31 МБ на 860 тыс. объектов (раньше было ~91 МБ); полный путь папки хранится один раз на блок.
- Результаты поиска несут признак папки, поэтому таблица не вызывает `is_dir()` на каждую видимую строку; папка результата форматируется один раз и кешируется.
- Кэш прошлого формата читается без переобхода диска; после файловых операций индекс не удаляется, а помечается устаревшим.
- Дата изменения форматируется лениво при первом показе строки и кешируется, а не пересчитывается каждый кадр.
- В покое приложение не перерисовывается: 0% CPU (проверено в release-сборке), ~100 МБ RAM в зависимости от кэша папок и результатов поиска.
- Release-сборка с fat LTO и `panic = "abort"`: `cargo build --release` → `target\release\korobka_explorer.exe` (~5,0 МБ).
- Можно открыть папку сразу: `korobka_explorer.exe "D:\Files"`.

## Планы

- Индекс по `$MFT`/USN journal (как в Everything) — отдельный режим с повышением прав и NTFS-парсером.
- Предпросмотр файлов и миниатюры, двухпанельный режим, сохранение настроек между запусками.
