# Launch kit

Ready-to-post drafts for Korobka Explorer. Publishing is manual: no Reddit/Hacker News/Habr accounts are configured in this repository.

## Assets

- Demo GIF: `docs/screenshots/demo.gif`
- Release: https://github.com/ivangameapps-lab/korobka-explorer-public/releases/tag/v0.5.0
- Repository: https://github.com/ivangameapps-lab/korobka-explorer-public

## Posting order

1. **Show HN** — Tuesday–Thursday, 9:00–11:00 US Eastern.
2. **r/rust** — the same day, afternoon.
3. **r/Windows** — next day, with a more user-oriented text.
4. **Habr** — a separate Russian article; do not copy the HN text.

Do not post the same link to five communities at once. Answer comments for the first 2–3 hours.
