# Habr: черновик статьи

**Заголовок:** Korobka Explorer: файловый менеджер на Rust/egui — поиск, корзина и длинные пути

**Лид:**

Написал файловый менеджер для Windows на Rust и egui. Не обёртка над Проводником, не Electron: один exe ~5 МБ, Win32-обход каталогов, компактный индекс поиска, своя корзина с восстановлением и поддержка путей длиннее 260 символов. В статье — что оказалось сложным и какие решения пришлось принять.

**План:**

1. **Зачем ещё один файловый менеджер.**
   - Ограничения Проводника, которые раздражали.
   - Почему Rust/egui, а не C#/WPF и не Electron.

2. **Архитектура.**
   - `eframe/egui` + `egui_extras` для виртуализированных таблиц.
   - Своя шапка, вкладки, хлебные крошки, контекстные меню.
   - Разделение: UI, `search`, `fs_ops`, `locks`, `archive`, `drives`, `i18n`, `path_util`.

3. **Поиск и индекс.**
   - Мгновенный фильтр текущей папки без диска.
   - `Enter` — рекурсивный поиск по папке, лупа — по тому.
   - Компактный формат: путь папки один раз на блок, элементы — имя + тип.
   - Параллельный обход, отдельный поток записи кэша.
   - Цифры: 888 тыс. объектов — ~1 с на 8 потоках; 2,25 млн — чтение кэша ~0,13 с.
   - Почему после файловых операций индекс перестраивается и как это ощущается.

4. **Длинные пути.**
   - `\\?\` и `\\?\UNC\`, где именно нужен префикс.
   - Какие вызовы Win32 ломаются на 260 символах.
   - Почему в UI показываем обычный путь.
   - Ограничение: открытие файла сторонней программой всё равно может зависеть от неё.

5. **Корзина.**
   - Своя папка `%LOCALAPPDATA%\Korobka\trash`.
   - Манифест `оригинал → перемещённый файл`.
   - Окно корзины: восстановление, выборочное удаление, очистка.
   - Почему это не корзина Windows и что это значит для пользователя.

6. **Файловые операции.**
   - Конфликты, прогресс, отмена, undo.
   - Блокировки через Restart Manager.
   - Защита от копирования папки внутрь себя.

7. **Мелочи, которые съедают время.**
   - Фокус: почему Delete не работал, пока фокус оставался в поиске.
   - Перерисовка прозрачного окна и акрил.
   - Локализация RU/EN.
   - Сохранение сессии и атомарная запись.

8. **Что дальше.**
   - Инкрементальное обновление индекса.
   - `$MFT`/USN journal.
   - Single instance.
   - Корзина Windows.
   - Preview.
